From a spark to the digital future

Each page of hamdaz.com is one chapter with its own element. Every clip starts or ends on the same frame: the spark, a single point of cyan light on navy. Because of that, any page can hand over to any other page and it always plays as one continuous story.

How the clips join

Home · in→Home · loop→Home · out→the spark→Services · in→Services · loop→…

On the site: a page opens by playing its in clip, then its loop plays behind the text. When someone clicks a link, the page plays its out clip down to the spark, and the next page picks up from the spark with its own in clip.

Steps in Higgsfield

  1. Make the 6 stills first: the spark plus one still per page. They lock the look, and every video is made between them.

  2. Make the clips with Start & End Frame (Pro or Ultimate plan; with Kling, use the General preset). In = spark → page still. Loop = page still → the same still. Out = page still → spark.

  3. Paste the style lock at the end of every image prompt. Use the same model and settings for every clip, so they match.

  4. Download and rename each file to the name shown on its card, then put them all in assets/video/ in the project. Tell me when they're in and I'll wire them up.

The spark must sit in the same spot in every clip, about 62% across and halfway down. That's where each element is centred, so the in and out clips meet exactly.

    If a clip doesn't match

    The in clip ends slightly differently from the still: fine. The site cross-fades into the loop, so small differences don't show.

    The loop jumps when it restarts: regenerate it with "locked-off camera, no camera movement" at the start of the prompt. With the same image as start and end frame, Higgsfield may otherwise orbit the camera.

    The element drifts to the centre of the frame: add "positioned on the right side of the frame" to the prompt and regenerate the still first.
