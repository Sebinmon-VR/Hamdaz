# Google Ads for hamdaz.com

Search ads that put Hamdaz at the top of Google, in the "Sponsored" results, when someone in the UAE searches for any of our services. Every service has its own ad group, and each ad group's ads and keywords point to that service's own page.

## What is here

| File | What it is |
|---|---|
| `plan.mjs` | The whole campaign: budgets, keywords, headlines and descriptions for all 38 services. Edit this one. |
| `build.mjs` | Checks the plan against Google's limits (headline 30 characters, description 90, path 15) and that every service on the site has an ad group, then writes the import files. |
| `import/` | The files to import, generated by `node docs/google-ads/build.mjs`. Do not edit them by hand. |

**Shape:** 9 campaigns (one per service area) → 38 ad groups (one per service) → 405 keywords (phrase match, plus exact match for each group's top 3) and one responsive search ad per group (up to 15 headlines, 4 descriptions). There is one shared list of 30 negative keywords (jobs, salary, course, free, DIY…).

**Budget as planned:** AED 295 a day in total, or about AED 9,000 a month if every campaign runs:

| Campaign | AED/day |
|---|---|
| ELV & Security Systems | 50 |
| Cybersecurity | 45 |
| Audio Visual | 40 |
| Software Development | 40 |
| Networking & Wi-Fi | 30 |
| Cloud & Infrastructure | 30 |
| AI, Data & Automation | 25 |

Every campaign is imported **paused**, so nothing spends until someone switches it on. To spend less, switch on only the first three or four campaigns.

## Before switching anything on

The site side is built:
- **Contact form.** It sends straight to the ERP (`enquiry` in `src/data.mjs`, the ERP's `/website/enquiry`). Each enquiry is saved under **Website Enquiries** in the ERP with the ad, campaign and search that brought the visitor (utm tags and gclid). If the ERP can't be reached, the form offers WhatsApp and email with the message ready.
- **Privacy policy** at `privacy.html`, linked from the footer, the form and the cookie banner. Have it read before launch.
- **Google tag with Consent Mode, the cookie banner, and conversion events** (`assets/js/track.js`): form sent, phone tap, WhatsApp, email.

What's left:
1. **Switch the tag on.** In Google Ads, create four conversions under Goals → Conversions → New → Website → "Set up manually": *Contact form*, *Phone call click*, *WhatsApp click*, *Email click*. Each one's tag setup shows `send_to: 'AW-123456789/AbCdEf…'`. Put the `AW-…` id and each label in `tracking` in `src/data.mjs`, then run `node build.mjs` and upload. The cookie banner and "Cookie settings" link appear only once the id is set.
2. **Check Google can see it.** Use Google Tag Assistant (tagassistant.google.com) on hamdaz.com: send a test enquiry, and the *Contact form* conversion should fire. Delete the test from the ERP afterwards.
3. **The new site live.** The ads point to `https://hamdaz.com/service/<slug>/`. Those pages are on the `redesign/home-story` branch. If the live site is still the old one, check that each address opens the right page before the ads run.
4. **The ERP deployed** with the website-enquiries change and its database migration. Until then, the form falls back to WhatsApp and email.

## Setting it up

1. Create the account at ads.google.com in **expert mode**, with currency **AED** and time zone **Dubai**. Skip the guided "smart" campaign it offers.
2. Install **Google Ads Editor** (free) and sign in to the account.
3. In Editor, use **Account → Import → From file** and import the files in `import/` **in their numbered order (1 to 6)**. Check the preview of each one before you apply it: the column names follow Editor's own, but confirm Editor reads "Criterion Type" as the match type and "Budget" in AED.
   - If the negatives file does not import cleanly, use `negative-keywords.txt` instead. In the Google Ads website, open **Tools → Shared library → Negative keyword lists**, paste it in, and apply the list to all 9 campaigns.
4. For each campaign, check the following:
   - **Networks:** Google Search only. Untick Search Partners and the Display Network.
   - **Locations:** United Arab Emirates, set to **"Presence: people in or regularly in"** your locations, not "interest in".
   - **Ad schedule:** all days to start with. After a month, cut the hours that bring no enquiries.
5. Set **bidding** (it is not in the import files):
   - **For the first 2–4 weeks:** use **Target impression share**, with location "Absolute top of results page", target 70%, and a maximum CPC limit of AED 20. This is the setting that keeps the ads at the very top.
   - **After about 30 conversions:** switch to **Maximize conversions**, so Google bids for the searches that turn into enquiries, not only for the top spot.
6. Add these **assets** at account level, so they appear on every ad:
   - **Sitelinks:** Services (`/services.html`), Projects (`/projects.html`), Certifications (`/certifications.html`), Contact (`/contact.html`).
   - **Call:** +971 2 626 5780. Use the main number chosen in `docs/SEO.md`.
   - **Location:** link the Google Business Profile.
   - **Callouts:** "MCC Certified", "ISO 9001, 14001 & 45001", "Abu Dhabi Office", "Support After Handover".
7. Switch the campaigns on.

## Every week after launch

- **Search terms report:** add any irrelevant searches as negatives. Typical ones are job seekers, students and home users if you don't do residential work.
- **Keywords:** pause any keyword with clicks but no enquiries after about AED 300 spent. Raise the budget on campaigns where enquiries come in at a good cost.
- **Ads:** keep the best-performing headlines and replace the ones Google rates "Low".

## Changing the plan

Edit `plan.mjs` and run `node docs/google-ads/build.mjs`. If a line is too long, or a service has no ad group, it writes nothing and lists what to fix. Then import the changed file again in Editor.

Keep every claim in the ads true. Don't use "free", "best", "No. 1" or "official partner" unless we can prove it. Don't use other companies' brand names in ad text, beyond the platforms we work with.
