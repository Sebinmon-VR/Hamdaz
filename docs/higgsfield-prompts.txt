HAMDAZ — HIGGSFIELD STORY CLIPS
"From a spark to the digital future"

HOW IT WORKS
Every clip starts or ends on the same frame: THE SPARK (a point of cyan light on navy).
Each page has 3 clips: IN (spark -> page still), LOOP (page still -> same still), OUT (page still -> spark).
Use Higgsfield "Start & End Frame" (Pro/Ultimate; with Kling use the General preset). Make all stills first.

SPECS
16:9 · 1920x1080 or 1280x720 · MP4, no audio · In/Out 4-5 s · Loop 5-10 s
Element on the right half (centred ~62% across, halfway down); left half and bottom-left dark. No text, logos, people or watermarks.
Save every file in assets/video/ with the exact name given.
